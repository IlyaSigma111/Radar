VK Radar

VK community scanner with radar UI

Download GitHub

Features

Spam Filtering

50+ built-in patterns automatically detect and filter ads, bots, and junk across every community you scan.

Rich Metadata

Comments, views, and reposts displayed on every card so you can assess engagement at a glance.

Local Storage

All data lives on your disk. No external servers, no telemetry. Full privacy, full control.

Adaptive Rate Limit

Automatically adjusts request intervals to stay within VK API limits without manual tuning.

How It Works

1

Install

Download and run the installer.

VK-Radar-Setup.exe
2

Configure

Add your VK token to the environment file.

.env
3

Run

Start the scanner and the web UI.

node test-scanner.js + npx next dev
